# Política de branches

- `main` guarda especificação e código que já passou no teste automático local.
- Trabalho novo usa `feat/<id>-descricao`, em minúsculas. Exemplo: `feat/t020-config-toml`.
- Não misturar uma tarefa de áudio com uma tarefa de interface no mesmo branch.
- Esta rodada de 21/10/2026 foi commitada direto em `main` porque o pedido do proprietário foi esse.
- Tag de release do produto só depois do gate correspondente. A tag `2.5.6` citada nos documentos é do Mixxx upstream, não uma release do DeckBridge.
