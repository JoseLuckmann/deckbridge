# Prova A0 no tablet

**Estado da escuta:** `BLOCKED_HARDWARE`. O acesso ao aparelho ainda vai demorar. Este texto diz como instalar e o que mandar de volta. Não é resultado de teste.

O tablet alvo é um Galaxy Tab S6 Lite. O modelo exato não está confirmado. O app lê o modelo, a versão do Android e, quando o sistema informa, o SoC. Não adivinha Exynos nem Snapdragon a partir do nome.

## Instalar

1. Copie `deckbridge-debug.apk` para o tablet.
2. Abra o arquivo. Se o Android pedir, permita instalar desta fonte.
3. Abra o DeckBridge. A primeira tela é o diagnóstico.
4. Ligue a DDJ-400 no USB do tablet, com o mesmo cabo do djay. Sem hub e sem outro aparelho no meio.

## O que fazer com a controladora

1. Toque em Atualizar dispositivos. Veja se a DDJ aparece na lista.
2. Toque em Tom no master. O som deve sair nas caixas.
3. Toque em Parar. Toque em Tom no fone. O som deve sair só no fone.
4. Marque o que você ouviu. Se o app disser que abriu só 2 canais, o tom do fone não foi para os canais 3–4.
5. Toque em Ler MIDI, gire o browse ou aperte LOAD, e veja se o nome do mapa aparece.
6. Toque em Compartilhar relatório e envie o texto inteiro.

O relato de que o djay já separou master e fone neste tablet fica no relatório como referência. Não substitui estes passos.

A tela Decks toca MP3 ou WAV escolhido no tablet. Ela não mede os 4 canais. O app não grava no pendrive.
