# Benchmarks e coletas

Nada nesta pasta é prova de palco.

- `T004-live-host.json` é a máquina em que o código foi escrito. Não é um Raspberry e não tinha a DDJ-400.
- `T006-mixxx-smoke.json` registra que o programa Mixxx não estava instalado.
- `T017-desktop-15min.json`, quando existir, é uma amostra do computador, sem Mixxx tocando. Não vale para o Raspberry e não diz quantos cortes de áudio houve.
- O perfil `high` / `mid` / `low` é uma regra de RAM e núcleos. Não é medida de latência.
